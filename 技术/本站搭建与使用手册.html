本站搭建与使用手册

本文档完整记录 MaxLOL 网站的搭建过程、系统架构与日常使用工作流。 网站由 Obsidian 笔记库 + Quartz 静态站点生成器 + GitHub Pages 免费托管构成。

一、系统总览

┌─────────────────────────────────────────────┐
│  Obsidian 笔记库 (E:\MaxVault)              │
│  ├─ 私密区：经历/知识/每日笔记（永不上线）   │
│  └─ 公开区：05-Public（发布到网站的内容）     │
└──────────────────┬──────────────────────────┘
                   │ 读取 05-Public
                   ▼
┌─────────────────────────────────────────────┐
│  Quartz v5 静态站点生成器 (WSL)             │
│  ├─ 双向链接/图谱/搜索/深色模式             │
│  ├─ 黑红主题 + 彩虹动效 (custom.scss)        │
│  └─ 发布记录时间线（本地插件）               │
└──────────────────┬──────────────────────────┘
                   │ git push (gh-pages)
                   ▼
┌─────────────────────────────────────────────┐
│  GitHub Pages (https://havvmax.github.io)  │
│  免费域名 · 全球 CDN · 1-2 分钟自动部署      │
└─────────────────────────────────────────────┘

核心理念：一套笔记库、两种输出。私密笔记自由记录，公开内容手动挑选后一键发布。

二、技术栈

组件选型说明
笔记管理Obsidian (Windows 原生版)本地 Markdown 纯文本，永不锁死数据
站点生成Quartz v5.0.0原生支持 Obsidian 双向链接、图谱
托管GitHub Pages免费，绑定 havvmax.github.io 域名
部署SSH (443 端口) + 本地脚本免 token，双击 bat 一键发布
主题自定义 SCSS黑红主题 + 彩蛋级彩虹动效

三、目录结构

E:\MaxVault\
├── 00-Inbox\            # 📥 快速捕获（新笔记默认落点）
├── 01-Daily\            # 📅 每日笔记（防遗忘核心）
├── 02-Experiences\      # 🧭 经历与经验（人生经历/经验教训/方法论）
├── 03-Knowledge\        # 📖 知识沉淀（技术/其他）
├── 04-Projects\         # 🚀 进行中的项目
├── 05-Public\           # 🌐 公开区（唯一发布到网站的目录）
│   ├── index.md         #    网站首页
│   ├── 发布记录.md      #    时间线数据（发布时自动写入）
│   ├── 经历\index.md    #    板块首页（介绍 + 文章列表）
│   ├── 技术\index.md    #    板块首页
│   │   └── 本站搭建与使用手册.md
│   └── 心理学\index.md  #    板块首页
│       └── 《微表情心理学》.md
├── 99-Templates\        # 🧩 笔记模板（每日/经历/技术/公开）
├── 99-Attachments\      # 🖼️ 附件（图片等）
├── README.md            # 快速入门
└── 使用手册.md           # 日常使用指南

安全边界：Quartz 构建只读取 05-Public 目录，其余目录物理上不会进入网站。 板块结构约定：新文章放进板块文件夹（经历/、技术/、心理学/）；板块首页用文件夹内的 index.md，不要在根目录放和文件夹同名的 .md（会导致站点生成两个同名不同内容的页面）。

四、部署架构

4.1 关键文件

文件位置职责
deploy.shquartz-site/一键发布：记总结 → 构建 → 推送
deploy-config.txtquartz-site/仓库地址配置（SSH 免密）
quartz.config.yamlquartz-site/站点标题/颜色/组件配置
custom.scssquartz-site/quartz/styles/主题定制与动效
timeline 插件quartz-site/quartz-local/timeline/左侧栏发布记录时间线
sidebar-clock 插件quartz-site/quartz-local/sidebar-clock/侧边栏实时时钟 + 日期
发布网站.batWindows 桌面双击入口，调用 WSL 中的 deploy.sh

4.2 发布流程（deploy.sh 做的事）

  1. 定位 node：WSL 非交互 shell 不加载 nvm，脚本自动引入
  2. 准备 SSH 密钥：从 Windows 复制 id_rsa，走 443 端口连接 GitHub
  3. 询问总结：提示输入一句话（git commit 风格），可留空
  4. 写入时间线：把 时间 — 总结 插入 05-Public/发布记录.md 顶部
  5. 构建：quartz build --directory 05-Public，输出静态文件
  6. 推送：git 提交并 force-push 到 gh-pages 分支
  7. 生效：GitHub Pages 自动构建，1-2 分钟后网站更新

4.3 免 token 原理

Windows 的 SSH 密钥（C:\Users\lenovo\.ssh\id_rsa）已绑定 GitHub 账号，部署通过 ssh -p 443 git@ssh.github.com 认证（国内网络 22 端口常被屏蔽，443 可用）。

五、发布记录时间线

  • 数据文件：05-Public/发布记录.md，每行一条 - 日期 时间 — 总结
  • 渲染组件：本地 Quartz 插件（timeline），在左侧栏绘制垂直时间线
  • 触发方式：每次发布时自动插入一条；也可手动编辑该文件补记历史
  • 排序：最新在前（新记录插入到标题行下方第一行）

六、主题定制要点

6.1 颜色（quartz.config.yaml → theme）

变量深色模式值用途
light#0d0d0d页面背景（纯黑）
darkgray#f0ece3正文文字（暖白）
secondary#e63946链接/强调（红）
tertiary#c1121f次级强调（深红）

6.2 动效（custom.scss）

  • 顶部 3px 彩虹流动细线（全站）
  • 首页大标题彩虹渐变文字（仅首页，body[data-slug="index"] 限定）
  • 链接悬停：彩虹下划线 + 变亮红
  • 左侧站点标题：红色渐变流动
  • 页面渐入动画、红色选中高亮、红色滚动条

6.3 已知注意

  • background-clip: text 动画在无 GPU 的无头浏览器中渲染异常，真实浏览器正常
  • 侧栏背景设 transparent 以与主内容同底色，仅留微红边框

七、日常使用工作流

7.1 记录（防遗忘）

  1. 随手记：Ctrl+P → 新建笔记，默认进 00-Inbox，先记下来再说
  2. 每日笔记：Ctrl+P → 打开今日笔记，睡前写三行
  3. 沉淀：有深度的内容用模板转正式笔记，移入 02-Experiences / 03-Knowledge
  4. 回顾：图谱视图 / 随机笔记 / 每周翻每日笔记

7.2 发布

  1. 公开内容写进 05-Public（或从私密笔记改写后放入）
  2. 双击桌面「发布网站.bat」
  3. 输入一句话总结 → 回车
  4. 等 1-2 分钟，Ctrl+Shift+R 强制刷新网站

7.3 常用快捷键

操作快捷键
命令面板Ctrl+P
全库搜索Ctrl+Shift+F
今日笔记Ctrl+P → 打开今日笔记
图谱视图Ctrl+G
发布双击桌面 bat

八、故障排查

问题原因与解决
bat 报 node: command not founddeploy.sh 已内置 nvm 定位，更新后重试
发布后网站没变GitHub Pages 部署需 1-2 分钟，先强制刷新
时间线不更新检查 发布记录.md 格式（- YYYY-MM-DD HH:MM — 总结）
推送失败检查 Windows 的 id_rsa 是否仍绑定 GitHub 账号

九、扩展方向

  • 绑定自定义域名（修改 quartz.config.yaml 的 baseUrl 并启用 cname 插件）
  • 添加评论（giscus，GitHub Discussions 驱动）
  • 站点搜索优化、RSS 订阅（Quartz 已内置 content-index 支持）
  • 更多本地插件（观察 quartz-local/ 目录模式即可扩展）
