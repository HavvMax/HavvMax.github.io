傻瓜式教程教你串流手机电脑

傻瓜式教程教你串流手机电脑

2026年10月25日18分钟阅读

零基础教程：用手机低延迟操控家里的电脑

不需要懂网络，照着一步一步点就行。 全程大约 40 分钟，其中大部分时间在等安装。 做完之后：手机能像坐在电脑前一样操作它，延迟 30ms 左右，还能串流玩游戏。

这份教程能帮你做到什么

  • 在外面上网时，用手机打开家里的电脑
  • 用手机看电脑屏幕、点鼠标、敲键盘
  • 移动设备连接键鼠延迟低到可以玩游戏

开始之前：先准备这些东西

需要什么说明大概花费
一台 Windows 电脑Win10 / Win11 都行你已经有
一部安卓手机安卓 10 以上你已经有
一个 Tailscale 账号免费注册0 元
一台云服务器（VPS）国内的，有公网 IP约 30~60 元/月（可免费试用）

没有 VPS 也能做，只是速度会慢一些（走官方服务器，延迟 80~200ms）。 想要低延迟就必须有 VPS，这一步不能省。

先认识 5 个词

词解释
Tailscale一个软件，装上之后两台设备就像在同一个局域网里
DERPTailscale 的”中转站”。两台设备直接连不上时，流量就从这里绕一下
Sunshine装在电脑上的软件，负责把屏幕画面传出去
Moonlight装在手机上的软件，负责接收画面、把按键传回去
RustDesk另一种远程桌面，不接键鼠也能用触屏直接操作电脑

简单理解：Tailscale 负责”连得上”，Sunshine + Moonlight 负责”看得清、操作顺”。

第一步：让电脑和手机互相看见（Tailscale）

1-1 注册账号

  1. 打开浏览器，访问 https://login.tailscale.com/start
  2. 用 Google / 微软 / GitHub 账号登录都行（推荐 Google）
  3. 登录成功后，你会看到一个空的控制台页面

✅ 检查点：页面顶部能看到 “Machines” 字样。

1-2 电脑上安装 Tailscale

  1. 打开 https://tailscale.com/download/windows
  2. 下载安装包，双击安装（一路 Next）
  3. 安装完成后，任务栏右下角会出现 Tailscale 图标
  4. 点图标 → Log in → 浏览器会跳转 → 点 Connect

✅ 检查点：网页控制台的 Machines 里出现你的电脑，状态是 Connected。

1-3 手机上安装 Tailscale

  1. 在手机应用商店搜索 Tailscale，或者打开 https://tailscale.com/download/android
  2. 安装后打开，点 Sign in，用同一个账号登录
  3. 登录后点 Connect，系统会弹窗询问是否允许创建 VPN，点允许

✅ 检查点：网页控制台的 Machines 里出现你的手机。

1-4 记住两个地址

回到网页控制台 https://login.tailscale.com/admin/machines，你会看到每台设备都有一个 100.x.x.x 开头的地址。

把这两个地址记下来（或者截图）：

  • 电脑的地址：100.______
  • 手机的地址：100.______

这个地址就是以后手机”访问电脑”用的地址，像门牌号一样。

第二步：让连接变快（自建中转站 DERP）

为什么需要这一步？ Tailscale 官方的中转站在香港和东京，延迟 80~200ms，玩不了游戏。 在自己买的国内 VPS 上搭一个中转站，延迟能降到 20ms 左右。 这一步是整个教程里最关键的，也是最容易出错的，慢慢来。

2-1 买一台 VPS

以阿里云为例：

  1. 打开 https://www.aliyun.com，注册并实名认证
  2. 搜索”云服务器 ECS”，点立即购买
  3. 地域选**华北2（北京）**或离你近的城市
  4. 配置选最低配就行（1核2G 足够），系统选 Ubuntu 22.04
  5. 带宽选按固定带宽 5M（够用）
  6. 付款后，在控制台找到这台服务器，记下公网 IP（形如 203.0.113.10，这只是示例，以你控制台显示的为准）

✅ 检查点：你能用 SSH 工具（比如 FinalShell、Xshell、MobaXterm）连上这台服务器。

2-2 开放两个端口（重要！）

  1. 进入阿里云控制台 → 云服务器 ECS → 实例 → 点进你的服务器
  2. 找到安全组 → 配置规则 → 入方向 → 手动添加
  3. 添加两条规则：
端口范围协议授权对象说明
443/443TCP0.0.0.0/0中转站主端口
3478/3478UDP0.0.0.0/0打洞辅助端口

少开任何一个，后面都会失败。特别是 3478/UDP，最容易漏。

第三步：让手机看到电脑画面（二选一）

到这里要做个选择，两条路线解决的场景不一样：

你的情况选哪条体验
不接键鼠，只想在手机上点一点、看文档、改设置A 路线：RustDesk触屏直接操作，像用手机 App，延迟 100~200ms
要长时间打字、精确点选、接蓝牙键鼠、甚至玩游戏B 路线：Sunshine + Moonlight延迟 30~40ms，画面流畅，键鼠原生支持

两条路线可以都装，互不冲突。临时看一眼用 A，长时间干活用 B。

A 路线：RustDesk（不接键鼠，触屏直接操作）

适合：临时看一眼电脑、传个文件、改个设置、远程关机。

A-1 电脑上安装 RustDesk

  1. 打开 https://rustdesk.com/zh-cn/，点”下载”，选 Windows
  2. 双击安装，装完会自动打开
  3. 窗口里能看到”你的 ID”和一串”临时密码”

A-2 设置固定密码（这样手机每次连不用问你要密码）

  1. 点右上角的三个点（或齿轮图标）→ 设置
  2. 左侧选 安全
  3. 勾选 使用固定密码，输入一个自己记得住的密码，点应用
  4. 同一页往下，勾选 启用直接 IP 访问

✅ 检查点：主界面里原来的”临时密码”变成了”密码”，并且直接 IP 访问显示已开启。

A-3 手机上安装 RustDesk

应用商店搜索 RustDesk，或者打开 https://rustdesk.com/zh-cn/ 选 Android。

A-4 用 Tailscale 地址连接

  1. 手机打开 RustDesk
  2. 在 ID 输入框里，不要填 ID，直接填电脑的 Tailscale 地址：100.______
  3. 点 连接
  4. 输入 A-2 设置的固定密码

✅ 检查点：手机上出现电脑画面，手指点哪里电脑鼠标就点哪里。

RustDesk 的画面有推送帧延迟，看文档、改设置没问题，看视频和玩游戏会明显卡——那种场景请走 B 路线。

B 路线：Sunshine + Moonlight（接键鼠，舒适操作）

适合：长时间办公、打字、精确操作、玩游戏。

B-1 先确认电脑是什么架构（下错包会装不上）

按 Win + R → 输入 cmd → 回车，输入：

输出该下哪个
AMD64Sunshine-Windows-AMD64-installer.msi
ARM64Sunshine-Windows-ARM64-installer.msi

99% 的电脑是 AMD64。下错会提示”此安装程序包无法在您的处理器类型上运行”。

B-2 在电脑上安装 Sunshine

  1. 打开 https://github.com/LizardByte/Sunshine/releases/latest
  2. 在页面下方的 Assets 里，找到对应架构的 .msi 文件，点下载
  3. 下载完，右键 → 以管理员身份运行
  4. 一路 Next 安装完成

✅ 检查点：任务栏出现 Sunshine 图标。

B-3 设置 Sunshine 账号

  1. 打开浏览器，访问 https://localhost:47990
  2. 会提示”您的连接不是私密连接” → 点高级 → 继续前往
  3. 第一次进去要设置用户名和密码（自己记住）

✅ 检查点：能看到 Sunshine 的设置界面。

B-4 在手机/平板上安装 Moonlight

  1. 应用商店搜索 Moonlight Game Streaming，或者打开 https://moonlight-stream.org
  2. 安装后打开

B-5 配对（关键一步）

  1. 在 Moonlight 里点右上角的 + → Add PC
  2. 地址栏填电脑的 Tailscale 地址（就是第一步记下的 100.______），点 OK
  3. 点刚添加的电脑图标，会出现一个 4 位数字的 PIN
  4. 回到电脑，打开 https://localhost:47990 → 点顶部 PIN → 输入那 4 位数字 → 提交

✅ 检查点：手机上的 Moonlight 出现桌面画面。

❌ 连不上：

  • 确认手机和电脑的 Tailscale 都是 Connected 状态
  • 地址一定填 100. 开头的，不要填 192.168 或 10. 开头的

B-6 调整画质（按这个填就行）

在 Moonlight 里点电脑图标 → 设置：

项目填什么
分辨率1920x1080
帧率60
码率20 Mbps
HDR关

卡的话把码率降到 15，不要降分辨率。

第四步：日常使用

走 A 路线（RustDesk）

手机打开 RustDesk → 输入 100.______ → 输入固定密码 → 连上。

走 B 路线（Sunshine + Moonlight）

手机打开 Moonlight → 点电脑图标 → 选 Desktop → 开始串流。

关机后还能连吗？

能。但要按下面的设置做，否则电脑睡眠后会断线：

  1. 控制面板 → 电源选项 → 更改计划设置
  2. “关闭显示器”设为从不
  3. “使计算机进入睡眠状态”设为从不

如果电脑睡眠了，Tailscale 会断线，手机就连不上了。

电脑开机就自动连上？

  • Tailscale：右键图标 → Settings → 勾选 Start on Login
  • Sunshine：安装时默认已设为开机自启

最后：为什么这样配就能快

一句话版本：

  1. Tailscale 让手机和电脑能互相找到对方；
  2. 能直连时走直连，延迟最低；
  3. 直连失败时走 DERP，所以DERP要放在离你近的地方（国内 VPS）；
  4. 只想点一点就用 RustDesk，要舒服用键鼠就上 Sunshine + Moonlight——后者用硬件编码 + UDP 传输，专门为”实时画面”优化，比普通远程桌面快好几倍。

四步缺一不可，但最影响体验的是第 2 步和第 3 步的选择。
